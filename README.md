# 🧞 EduGenie - Google Gemini Powered Learning Assistant

EduGenie is an AI-powered learning assistant built using Google Gemini API. It helps students to get instant answers, summaries, and explanations in simple language.

### ✨ Features
- Instant doubt solving
- Subject-wise explanation (Science, Maths, History etc.)
- Simple language for students
- 24/7 Available

### 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python / Java
- AI Model: Google Gemini 1.5 Flash

### 🚀 How to Run
1. Get your API key from https://aistudio.google.com/app/apikey
2. Replace YOUR_API_KEY in Java script.js and App.py.txt
3. Open index.html in browser
